## What it does

- **Budgets by category.** Set up budget categories and log expenses
  against them as they happen.
- **Live charts.** Spending visualisations update the moment an expense is
  added, showing where the month is going category by category.
- **Recurring reminders.** Alerts for repeating bills so nothing slips.
- **Real-time sync.** Firebase keeps data consistent across sessions.

## Stack

Next.js on the front end, Firebase for data and real-time sync.
